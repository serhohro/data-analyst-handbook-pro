# 📊 Data Analyst Handbook PRO 

> Interactive Data Analytics Handbook covering Python, Pandas, NumPy, SQL, Excel, DAX, Power BI, Statistics and Business Analytics.

## 🚀 Overview

**Data Analyst Handbook PRO** is an interactive, offline-first learning and reference tool designed for Data Analysts.

It combines a command library, cross-stack comparisons, practical exercises, an interactive exam system, multilingual support, and optional local AI assistance in a single HTML application.

## ✨ Features

- 📚 **193+ analytical operations**
- 🔄 **Cross-Stack Matrix** — Python → Pandas → SQL → Excel → DAX
- 🧪 **Practice Mode** with random tasks and solutions
- 📝 **Interactive PRO Exam** with 30 randomized questions
- 📊 Automatic scoring and answer explanations
- 🔎 Smart Search
- 🤖 Optional local **Ollama AI** integration
- 🌍 Multilingual interface: English, German, Russian and Ukrainian
- 💻 Works as a standalone HTML application
- 🌐 Offline-first — no server required
- 💾 Exam results are stored locally in the browser

## 🔄 Cross-Stack Matrix

The same analytical operation can be compared across different technologies.

| Task | Python | Pandas | SQL | Excel | DAX |
|---|---|---|---|---|---|
| Aggregation | Python | `groupby()` | `GROUP BY` | Pivot Table | DAX |
| Filtering | Conditions | `query()` | `WHERE` | FILTER | `CALCULATE()` |
| Joining | Logic | `merge()` | `JOIN` | XLOOKUP | Relationships |
| Ranking | Sorting | `rank()` | `ROW_NUMBER()` | RANK | `RANKX()` |
| Missing Values | `None` | `isna()` | `IS NULL` | `ISBLANK()` | `ISBLANK()` |

## 🧪 Practice Mode

Practice Mode allows users to:

1. Select a topic.
2. Receive a random task.
3. Try to solve it independently.
4. Reveal the solution after attempting the task.

## 📝 Interactive PRO Exam

The built-in exam system provides:

- 30 questions per exam
- Random question order
- Automatic answer checking
- Score calculation
- Answer explanations
- Final performance level
- Retake functionality

## 🤖 Smart Search + Ollama

The application first searches its local knowledge base.

If no suitable answer is found, users can optionally send the query to a locally running Ollama model.

```text
User Query
    ↓
Local Knowledge Base
    ↓
Match Found?
   ↙       ↘
 YES       NO
  ↓         ↓
Answer    Ollama
```

Internet access is not required for the core Handbook functionality.
